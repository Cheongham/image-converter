- `npm run check`: 통과
- `npm test`: 11개 단위 테스트 통과
- `tests/browser.html`: Chromium 기반 실제 브라우저에서 **40개 검증 통과**
- 배포 ZIP: 파일별 원본 바이트와 압축 해제 결과 대조 통과
- 배포 HTML의 로컬 JS·CSS·아이콘 링크와 WASM 파일 존재 확인

## 실제 다운로드 파일 확인

실제 변환기 화면에서 4개 입력 파일을 WEBP로 변환하고 ZIP을 내려받았습니다. 다운로드한 ZIP을 Python Pillow로 다시 읽어 네 파일 모두 실제 WEBP로 디코딩되는 것을 확인했습니다.

- `transparent-converted.webp`: 120×80, 투명 영역 alpha=0
- `photo-converted.webp`: 120×80
- `animated-converted.webp`: 80×60, 1프레임
- `transparent-converted-2.webp`: 120×80, 원래 WEBP 유지

중복 기본 파일명에 자동으로 번호가 붙는 것도 확인했습니다. 이 다운로드 검증 파일은 개인 다운로드 폴더에서 검사한 후 테스트 폴더에 복사했지만, Git 및 배포 ZIP에서는 제외했습니다.

## 범위와 한계

- 실제 Safari·Firefox 브라우저 및 스마트폰 하드웨어별 검증은 수행하지 않았습니다.
- 네이티브 WEBP가 지원되는 환경에서도 보조 인코더 경로를 강제로 실행해 실제 WEBP 결과와 투명도를 확인했습니다.
- GIF·WEBP 간 애니메이션 변환을 지원하는 것은 아닙니다. 다른 형식으로 변환할 때 첫 프레임만 저장한다는 UI 안내를 제공합니다.
- 케미클라우드의 실제 서버 업로드 및 운영 도메인에서의 검증은 별도입니다. 이 기록은 로컬 HTTP 미리보기에서의 기능·패키지 검증입니다.
